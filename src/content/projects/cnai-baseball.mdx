## 개요

8만 명 이상이 이용하는 야구 팬 플랫폼의 전체 구조를 파악하고 유지보수를 담당했습니다. 레거시 코드에서 비롯된 데이터 불일치 문제와 이벤트 추첨 로직의 설계 결함을 발견하고 수정했으며, 수동으로 운영되던 운영 체계 여러 곳을 자동화했습니다.

## 이벤트 추첨 시스템 재설계

**배경** 추첨 시스템 개편 요청을 받아 기존 로직을 분석했습니다. 유저를 외래키로 갖는 별도 테이블에 당첨 횟수가 누적되고, 그 숫자가 높을수록 추첨에서 불리해지는 레거시 정책이 그대로 남아 있었습니다. 반복 구매 사용자일수록 오히려 불이익을 받는 역설적인 구조였습니다.

**행동 & 결과** 모든 티켓 구매자를 동등한 조건으로 포함하는 랜덤 추첨 시스템으로 재설계해 공정성을 확보했습니다.

## 추첨 명단 엑셀 업로드 자동화

**배경** 추첨 대상 명단을 관리자가 백엔드 시스템에 직접 수작업으로 입력해야 했습니다. 이틀씩 소요되던 작업으로 이벤트 운영 일정에 영향을 줬습니다.

**행동 & 결과** 엑셀 파일을 업로드하면 데이터를 파싱해 백엔드 서버에 자동으로 전송하는 기능을 구현했습니다. 이틀씩 소요되던 명단 관리 작업이 **한 시간 안에 완료**될 수 있게 됐고, 플랫폼 관계자로부터 직접 긍정적인 피드백을 받았습니다.

## 멤버십 코드 자동 발급

**배경** 관리자가 백엔드 시스템에 멤버십 코드를 직접 입력한 뒤 사용자에게 전달하는 수동 방식으로 운영됐습니다. 가입자가 늘수록 관리자 부담이 커지는 구조였습니다.

**행동 & 결과** 백엔드에서 코드를 자동 생성·발급하는 로직으로 전환해, 관리자 개입 없이 가입 시 코드가 자동 발송되도록 개선했습니다.

## 신규 이벤트 기능 출시

**배경** 기존 쿠폰 추첨 외에 신규 이벤트 참여 시스템을 추가해달라는 요청을 받았습니다.

**행동 & 결과** JSP 화면을 구현하고 API를 연동해 기능을 출시했습니다.

## 트러블슈팅

### 아이핀·PASS 인증 오류

아이핀·PASS 인증이 특정 시점부터 실패하기 시작했습니다.

오류 로그와 응답 코드를 분석해 외부 API 측 문제로 범위를 좁혔습니다. 동작했던 시점과 안 되던 시점을 추적해 비교한 결과, 협업사 내부 인증서 만료가 원인임을 특정했습니다.

협업사에 직접 이슈를 공유해 해결했습니다.

### Google Play 정책 위반 복구

Google Play 정책 위반으로 앱이 스토어에서 내려갔습니다.

개인정보 처리방침 미비가 원인임을 파악했습니다. 수집 항목을 명시하고, UI 접근성을 개선하고, 데이터 보안 설문지를 재작성해 앱을 복구했습니다.

### 티켓 사이트-플랫폼 데이터 불일치 / 포인트 미지급

레거시 코드로 인해 티켓 사이트 정보와 플랫폼 데이터가 불일치했고, 티켓 구매 시 포인트가 정상 지급되지 않는 로직 오류도 있었습니다.

각 케이스의 데이터 흐름을 추적해 원인을 파악하고 수정했습니다.
