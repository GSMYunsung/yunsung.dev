## 개요

누적 다운로드 300만 건, 제휴 렌터카사 600여 개 규모의 렌트카 예약 플랫폼 카모아의 유지보수와 신규 기획 개발을 담당했습니다. Vanilla JS와 Pug 템플릿으로 오랫동안 운영되던 코드베이스를 React로 점진적으로 전환하는 작업을 맡았습니다.

## React 점진적 전환

**배경** Vanilla JS와 Pug 템플릿으로 운영되던 코드베이스는 상태 관리가 여러 곳에 분산돼 같은 필터인데도 서로 다른 상태를 참조하는 문제가 있었습니다. 유지보수 가능한 구조로의 전환이 필요했습니다.

**행동 & 결과** 커스텀 훅으로 상태를 관리하고 배럴 파일로 진입점을 단일화하는 구조를 기본 컴포넌트 10여 개에 일관되게 적용했습니다. 조건이 바뀌어도 외부 코드를 건드리지 않고 훅과 컴포넌트만 교체하면 되는 구조를 만들었습니다.

## 숙박페스타 이벤트 필터 설계

**배경** 숙박페스타는 이벤트 기간에만 활성화되는 임시 필터로, 언제든 켜고 끌 수 있어야 했습니다. 기존 필터 상태는 커스텀 훅 안에 있었는데 숙박페스타 필터는 그 상태들과 독립적으로 동작해야 했고, useState가 여러 곳에 분산돼 같은 필터인데 서로 다른 상태를 바라보는 문제도 있었습니다. 나중에 다른 조건으로 대체될 가능성도 고려해야 했습니다.

**행동 & 결과** 전용 훅을 분리해 활성화 여부를 플래그 하나로 제어하고, 조건 변경 시 연관 필터 초기화도 훅 내부에서 처리하도록 정리했습니다. 필터 컴포넌트는 배럴 파일로 진입점을 단일화해, 조건이 바뀌어도 외부 코드를 건드리지 않고 내부만 교체하면 됩니다.

## 추첨 시스템 재설계

**배경** 추첨 시스템 개편 요청을 받아 기존 로직을 분석했습니다. 유저를 외래키로 갖는 별도 테이블에 당첨 횟수가 누적되고, 그 숫자가 높을수록 추첨에서 불리해지는 레거시 정책이 그대로 남아 있었습니다. 반복 구매 사용자일수록 오히려 불이익을 받는 구조였습니다.

**행동 & 결과** 모든 티켓 구매자를 동등한 조건으로 추첨하는 방식으로 재설계하고 프론트엔드 API 연동도 함께 업데이트했습니다.

## 트러블슈팅

### 홈 화면과 목록 간 가격 불일치

홈 화면에 표시되는 렌트카 가격이 목록에서 봤던 가격과 달라지는 오류가 있었습니다.

홈은 Pug, 목록은 React로 구성돼 있어 각자 다른 로직으로 가격을 계산하고 있었습니다. Pug는 React 상태를 참조할 수 없어 별도 구현이 유지되던 상황에서, 비즈니스 정책이 바뀌며 두 화면이 서로 다른 시점의 정책을 참조하게 된 게 원인이었습니다.

현재 정책을 기준으로 Pug 쪽 계산 로직을 맞추는 방식으로 해결했습니다. 이 외에도 기존 시스템 내 여러 건의 동작 오류 원인을 분석해 수정했습니다.
